[반드시 읽어주세요]
1. 이 ZIP은 이전에 다운로드한 Netlify *배포 결과물*을 바탕으로 제작됐습니다.
   원본 Netlify Functions, 데이터베이스 스키마 및 업로드 사진 데이터가 포함되지 않았습니다.
2. 따라서 새로운 Netlify 사이트에 그대로 배포하면 관리자 저장 및 온라인 앨범 자료가
   작동하지 않거나 비어 보일 수 있습니다. 이것은 사진 삭제를 뜻하지 않습니다.
3. 절대로 현재 정상 작동 중인 학교 홈페이지에 덮어쓰지 마세요.
4. 테스트는 별도 Netlify 테스트 프로젝트 또는 PC 로컬 프리뷰로만 하세요.
5. 실제 운영 적용 전 원본 소스(특히 netlify/functions, DB 연결 설정 및
   현재 관리자 콘텐츠 JSON 백업)를 확보하고 서버 코드를 병합해야 합니다.
6. 현재 ZIP에 기존 video1.mp4, video2.mp4, video3.mp4와 포스터, PPT 이미지가
   원본과 바이트 단위로 동일하게 보존됐습니다.
